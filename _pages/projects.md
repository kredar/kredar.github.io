## ResumeGPT

Instead of a static resume, I built a conversational AI assistant that answers questions about my professional background, skills, and expertise. Ask it about past roles, how I think about product strategy, which tools I've worked with, or anything else you'd find on a resume.

Built with LangChain, Retrieval Augmented Generation (RAG), GPT-3.5, and Streamlit.

## Lenny's Daily

A web app and Chrome extension built on 300+ Lenny's Newsletter posts and podcast transcripts, created during Lenny's Buildathon. Every time you open a new tab, you get:

- A spicy or aspirational quote from one of Lenny's podcast guests or newsletter posts, linked to its source
- A link to the latest podcast episode
- A link to the latest newsletter post
- Upcoming Lenny events

Built using DeepSeek V4, Claude Code, and Replit. The Chrome extension replaces your new tab page.
